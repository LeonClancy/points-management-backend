## 題目描述

請設計一個支援交易機制的點數系統，用來處理使用者儲值、扣點與失敗返還的流程。

系統情境如下：

* 使用者可以儲值點數
* 每次動作固定使用 100 點
* 動作開始時，系統需先處理這 100 點
* 若動作成功完成，則正式扣點
* 若動作未完成，則點數返還給使用者

請你從後端工程角度，自行設計這個系統，並說明：

1. 核心資料模型
2. 交易處理方式
3. 如何支援 nested transactions
4. 如何確保資料正確性與一致性
5. 若要走向正式環境，系統還需要補哪些能力

資料庫種類不限，請自行選擇並說明原因與 tradeoff。
